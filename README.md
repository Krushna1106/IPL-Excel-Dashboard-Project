# 🏏 IPL Team & Player Performance Dashboard (Microsoft Excel)

An interactive **IPL Team & Player Performance Dashboard** built entirely in **Microsoft Excel** to analyze team performance, player statistics, and match insights through dynamic dashboards, Pivot Tables, and data visualization techniques.

This project follows a **Star Schema Data Model**, separating **Fact** and **Dimension** tables to build a scalable and structured analytics solution. It provides valuable insights into team performance, player statistics, match outcomes, and key performance indicators (KPIs) using interactive filters and professional dashboard design.

## 📂 Dataset

The project consists of the following datasets:

- **fact_match** – Match-level information
- **fact_player** – Player performance statistics
- **dim_team** – Team details
- **dim_player** – Player details
- **Supporting Dimension Tables**
- Team Summary
- Player Summary
